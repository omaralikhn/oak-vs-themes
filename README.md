# Oak Themes

Dark VS Code color themes ported from oakcmd-ui.

## Themes

* Blue Hour Dark.
* Everforest Dark.
* Marigold Storm Dark.
* Gruvbox Material.

## Development

* Edit palettes in `scripts/palettes.mjs`.
* Run `npm run build` to regenerate `themes/*.json`.
* Run `npm run package` to build a `.vsix`.
